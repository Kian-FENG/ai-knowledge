`https://integrate.api.nvidia.com/v1/chat/completions`

`nvidia/nemotron-3.5-super-vl-120b-a12b`

Model ID returned in the API response:

`private/nvidia/nemotron-3.5-super-120b-a12b`

I have only tested text input so far. I have not submitted an image request because I would first like to verify the model identity.
