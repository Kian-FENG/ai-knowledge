# Anthropic内部研究：初级技术招聘占比下降，注意力成为约束

## Key Takeaways

Anthropic10月16日研究使用内部就业、AI使用、产出等数据及17名员工访谈。称2025年初以来初级技术员工占比由21%降至14%，初级技术招聘占比27%降至9%；技术招聘绝对人数仍增长，不能写成统一裁员比例。

研究称8月员工指挥的交互Agent运行小时约为人类工时六倍；Agent统计合并子Agent并排除超过30分钟等待，人类按人数×每周40小时估算，不能等同六倍有效劳动或生产率。跟踪192名采用与74名未采用工程师，采用非随机，公司增长等存在混杂。

相对泛化的就业预测，新增为一家前沿公司的组织内观察；只读主要发现、劳动需求及生产率方法和图注，不将产出代码量等同商业价值或推广全行业因果。日期仅到日。
