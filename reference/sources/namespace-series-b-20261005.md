# Namespace 披露 4,200 万美元 B 轮，扩展编码 Agent 的构建与测试设施

## Key Takeaways

Namespace 官网披露近期完成 4,200 万美元 B 轮，Scale Venture Partners 领投；累计融资 6,500 万美元。币种为美元，融资额不是收入、ARR 或估值，交易完成的具体日期未公布。
