# X推出统一订阅：Grok用量跨Cursor共享，第三方模型另计费

## Key Takeaways

官方10月12日公告将Grok、Grok Bot、Cursor和X Premium纳入一个订阅。新客户当天开始可用，全球及既有账户迁移在随后数日逐步展开；只有日期、无时区和准确小时，窗口边界不确定，前一期未收录。

公告美元月费为Plus 8、Premium 30、Super 100、Ultra 200；Grok额度可跨Grok应用、X内Grok和Cursor共享。Cursor的第三方模型在Premium及以上仍通过充值按API标价另付费，不能理解为所有模型包月不限量。

相对分开的助手、编码和社交套餐，增量是产品组合及共享额度。已读官方主文和价格表；税费、完整资格细则、折扣和实际账户开通未核实。
