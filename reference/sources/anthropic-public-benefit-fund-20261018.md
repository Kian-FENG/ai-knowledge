# Anthropic公共利益基金拟获5%股份，须经股东批准

## Key Takeaways

公司10月18日提出把5%股份拨入全资LLC公共利益基金，须股东批准；估值每较基线增加50%，董事会可酌情追加2%。

## Detailed Notes

股份安排不是现金捐赠到账。公告称与既有创始人和员工承诺合计约20%股份用于公共利益，不能把新增5%与20%相加；追加机制含董事会裁量，估值基线、治理和执行日期仍待披露。
