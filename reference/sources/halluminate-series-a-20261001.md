# Halluminate：融资与金融知识工作 RL 环境

## Key Takeaways

公司10月1日披露3,000万美元A轮融资，Oak HC/FT领投；累计融资3,850万美元，估值未披露。官网定位是知识工作评测与强化学习环境，首先关注金融服务。

## Detailed Notes

币种为美元，A轮与累计融资为不同口径，不能相加作为本轮金额。本文不把融资额当收入，亦不从收入运行率措辞推断ARR。公告早于本窗口，作为新对象发现的背景入库。
