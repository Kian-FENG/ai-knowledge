# HUMXN以家政服务补贴获取具身训练数据，公告为10月6日背景

## Key Takeaways

HUMXN官网10月6日公告推出家政服务补贴计划：在Minneapolis、Chicago、Miami，与服务商合作，为符合条件的住户支付水电、HVAC和清洁等服务，技术人员使用穿戴记录设备，将工作过程转成AI/机器人训练数据。

官网明确Thomas Unise为创始人，品牌HUMXN从事数据与训练业务；服务商获得报酬、住户获有条件补贴、公司获取专业操作示范。新纳入跟踪不等于当天成立或首发，不将10月17日媒体稿当作新计划。

仅核对官网品牌和产品归属；法定主体注册、融资、实际预约规模、收入、数据授权执行和机器人收益均未独立核验。
