# 台积电9月合并营收同比增54.6%，不能直接推导 AI 产能

## Key Takeaways

台积电10月8日披露2026年9月合并净营收约NTD511.86B，环比下降0.6%、同比增长54.6%；1—9月NTD3898.73B，同比增长41.1%。币种为新台币，期间不同须分列。
