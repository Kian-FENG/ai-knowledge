# Codex 输入框预测进入 beta：下一条提示仍由用户提交

## Key Takeaways

- 面向受支持地区、18岁及以上个人Pro账户，在最新Codex桌面端local及SSH聊天使用GPT-6 Astra或GPT-6.1 Sol。
- 根据当前聊天建议下一条消息；Tab插入可编辑文本，由用户提交。默认开启，可在General/Composer关闭。
- beta预测生成不消耗Codex限额或credits，提交消息仍按通常规则计费；不独立检索记忆或连接App资料。
