# Meta发布Muse Wonder系列：记忆与持续任务能力进入产品分发

## Key Takeaways

Meta于10月12日17:08:05 UTC发布Muse Wonder与Muse Wonder Full，基于Muse Spark，强调Active Memory跨会话提取相关信息、Active Focus持续尝试和错误恢复，并在重要行动前确认。

公告Takeaways明确Wonder当天通过Meta Model API与Muse Code提供，Wonder Full当天面向Muse Code订阅者；消费者Muse中的Wonder体验仍将随后向订阅者先行推出。不能把两款的API和消费端可用范围混为一谈。

相对此前持续Agent研究，本期新增模型与分发。已读新闻主文，未读研究博客全部评测/模型卡；“最强/领先”仅是厂商主张，不采用跨模型排名，权重许可和价格待核。
