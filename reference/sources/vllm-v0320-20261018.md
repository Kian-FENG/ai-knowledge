# vLLM v0.32.0正式发布：结构化决策、低精度KV与安全默认值

## Key Takeaways

GitHub API确认v0.32.0于10月18日06:50:48 UTC正式发布，prerelease=false；created_at为10月17日18:57:10 UTC，updated_at为18日10:23:45 UTC。

## Detailed Notes

相对v0.31.0，发布增加结构化决策端点/v1/systemone与读取checkpoint response_template的通用hf解析器，扩展NVFP4 KV适用GPU、ROCm四位KV路径和Elastic EP。默认CORS收紧、不可信图像限光栅格式，Python3.10支持被移除。官方性能百分比未补齐硬件/精度/并行/长度/并发与基线，因此本页不作吞吐排名。
