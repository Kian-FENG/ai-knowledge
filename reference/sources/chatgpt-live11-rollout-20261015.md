# ChatGPT Voice开始推送GPT-Live-1.1与Quip，新增多语言声音

## Key Takeaways

OpenAI帮助中心10月15日release notes称，GPT-Live-1.1与mini版本GPT-Live-1.1 Quip正在ChatGPT Voice推送；新增法、德、印地、日、韩、墨西哥西语及英语Bubbie声音，实际选项依地域和账户变化。
