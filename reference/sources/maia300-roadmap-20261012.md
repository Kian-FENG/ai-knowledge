# 微软：Maia 200已用于生产，Maia 300及多GW部署从2027年开始

## Key Takeaways

微软10月12日官方公告称Maia 200正在服务Microsoft Copilot和MAI生产工作负载，GitHub Copilot与Foundry计划年底前跟进；Maia家族多GW部署与Maia 300生产部署从2027年开始。日期没有精确时区/小时，边界不确定。

Maia 300面向长上下文和decode密集推理，采用TSMC N2P计算chiplet、独立内存/I/O功能及8个HBM4堆叠；公司披露18TB/s峰值带宽和950W TDP，96加速器机架167kW。均是设计披露，不能记为已经交付的扩产。

相对既有GPU服务供给，本期新增自研推理系统路线。未读外链技术论文；40% tokens/MW及7倍机架吞吐缺同口径模型/精度/长度/并发和GPU基线，不作通用排名或价格降幅。
