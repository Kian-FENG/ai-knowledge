# Anthropic 承诺三年提供 USD 1.5亿科研资源

## Key Takeaways

Anthropic 宣布未来三年提供价值USD150M的 Claude、Claude Code 和 API credits，并配套培训与技术支持，面向美国联邦科研项目。

公告称覆盖超过15个机构的数百项目；这是未来资源承诺，不是当期现金拨款、已确认收入或已经消耗的算力。
