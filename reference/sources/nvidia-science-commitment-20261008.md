# NVIDIA 承诺五年投入价值 USD 10亿的美国科研支持

## Key Takeaways

NVIDIA 公告未来五年提供价值USD1B承诺，覆盖高等院校科研、量子领域与支撑政府任务的云服务商，并参与Genesis第二阶段项目。
