# 星忆智能官网背景：从采集设备到具身数据产品

## Key Takeaways

官网把EgoKit、HBR Engine、AstraData列为星忆智能/AstrAlive体系。Blog为2026年7月10日v1.0背景，不能把本次发现写成10月22日产品发布。

## Detailed Notes

EgoKit采集视觉、手部姿态与触觉；HBR Engine执行清洗脱敏、标注和质量评估；AstraData提供训练和评测数据。性能和精度为厂商主张，未实测。10月22日媒体融资线索正文获取失败，轮次、金额、法定主体、成立日待公司/投资方/注册来源核对。
