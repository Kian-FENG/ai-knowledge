# NVIDIA与Cisco提出USFP光模块形态，开放多源规范仍待推进

## Key Takeaways

10月12日15:00 UTC官方公告USFP可插拔光模块形态，目标在接近OSFP尺寸中容纳16个全双工光通道、每通道400Gb/s，聚合最高12.8Tb/s；后续32通道属路线规划。聚合带宽与单通道速率分开。

公司计划在即将开展的多源项目中形成开放行业规范，并列出TE/Amphenol等生态伙伴。没有确认上市/交付日期、认证互操作或客户订单，不能记为正式规范发布和已量产。

相对普通光模块，本期新增更高端口密度的结构提案。4倍密度与1.3倍功耗是厂商设计比较，未得同口径实测，不直接推导网络成本下降。
