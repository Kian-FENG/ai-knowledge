# SWE-Duel论文公告：编码Agent互相出题，评测对象仍是模型与harness组合

## Problem and Method

arXiv本期RSS于10月12日公告SWE-Duel v1，提交于10月8日18:01:00 UTC。日期精度仅到天、边界不确定；是本期公告增量，不是提交日当天。

红方分三个上下文隔离会话实现功能、加入缺陷及封存测试，任务须通过功能/既有测试、失败于缺陷测试且能被同一Agent新会话盲修；蓝方不被告知存在缺陷，修复须过全部三类测试，再交换角色。

摘要报告11个model-harness组合、15个仓库、5种语言、1500轮；仅读摘要与版本史，未读全文预算和具体环境。不用不同harness的分数排列基础模型，也不把动态生成任务视为现实缺陷分布的完整替代。
